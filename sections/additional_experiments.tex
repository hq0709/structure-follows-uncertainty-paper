\section{Additional controlled experiments}
\label{app:additional}
\myparagraph{Fixed-length training.} The sequence policies use advantage actor-critic, a terminal reward of $\pm1$,
full-episode backpropagation, Adam, and gradient clipping at norm~1. Unless
specified, models use width 16, batch size 256, and a learning rate of $0.003$.
The fixed-length Born model uses neither state normalization nor angle
regularization, and it does not mix its hidden coordinates. The length
curriculum uses normalization and the group-angle penalty from
Section~\ref{sec:stab}. The independently tuned comparisons follow.

All new studies retain every reported seed, including failures. These are fresh
experiments rather than reconstructions of missing historical records. The main
sequence comparison gives each of eight families two learning rates
($0.001,0.003$) and two tuning seeds (100,101), each with 4,000 updates.
Selection averages the last three $L=14$ validation evaluations. Five independent
seeds (0--4) then run 6,000 A2C updates with batch 256, terminal reward,
and training lengths $4,6,8,10,12,14$. No long-horizon test is used for selection.
Cells report mean (sample SD) across seeds; each test uses 1,024 episodes per seed.
Gaussian observations have 16 dimensions and noise SD $0.25$. The group order
remains known. Hard angles use a straight-through quantizer while retaining
the original injection and readout, so this control is not an exact counter.

The modern adapters use the official DeltaProduct layer at commit
\texttt{d62241a}, with one 16-dimensional head, value expansion two, output gate,
negative eigenvalues, no convolution or forgetting, and a residual feedforward
block. DeltaNet uses one Householder update and DeltaProduct two. The CPU
recurrent kernel is verified against independent dense outputs and gradients;
streaming and full-sequence evaluation agree. These small RL adapters do not
reproduce full published configurations. Their results therefore cannot support
a universal comparison with all DeltaNet/DeltaProduct models.

\myparagraph{Valve protocol and optimization sensitivity.}
The complete policy learns from terminal reward on the operate task described
above. The validation-only selection protocol is identical across families,
using the last three $K=8$ evaluations. It was added after observing fixed-recipe
results, and is not preregistered. Selection with a 4,000-update budget can favor
a learning rate that is weaker after 6,000 updates; we therefore also retain
the full fixed-$0.003$ study rather than reporting only selected baselines.
Each selected-policy test uses 4,096 episodes per seed and condition. The
programmed oracle succeeds on every evaluated horizon; the learned classical
counter is a separate model that learns observation-conditioned cyclic belief
updates and an action head. Twenty animated episodes per horizon ($K=8,32$)
for each of 25 fixed-recipe policies give 1,000 simulator episodes. These use
scripted valve poses and do not establish contact-driven manipulation.

\myparagraph{Image observations.}
A shared CNN and the memory are trained jointly from raw MNIST images. Odd
digits constitute latent events; only terminal reward supervises their count
modulo $k$. There is no digit-classification loss or pretrained perception.
Training uses the first 50,000 training images; validation uses the remaining
10,000; evaluation uses the separate official test set. Training lengths
$1,2,4,6,8$ include short credit-assignment paths. A2C uses batch 128, learning
rate $0.001$, and 6,000 updates; evaluation uses 2,048 episodes per seed.
The unregularized variant was added after initial failures; both variants
are retained. These tests do not establish broad visual robustness.

\myparagraph{Frozen-state supervised probes.}
We freeze identical recurrence checkpoints and fit readout heads on the same
6,144 labelled examples, using identical minibatch index streams for 6,000 Adam
updates at learning rate $0.003$. This is supervised fitting, not RL learning.
The absolute-linear head sees all real and imaginary channels. The invariant
quadratic head sees every pairwise relative-phase product and has more parameters.
Both Born and invariant-quadratic heads fit the clean parity training set
perfectly, yet differ in extrapolation. The apparent Born advantage at $L=80$
weakens at $L=160$ and does not consistently extend to $k=3$ or noisy inputs.
All 60 fitted heads were replayed, reproducing every test accuracy exactly.
These results support a protocol-specific parameterization benefit, not necessity.
