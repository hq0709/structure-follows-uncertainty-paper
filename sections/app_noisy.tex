\section{Noisy Event Features and Image Observations}
\label{app:noisy}
Section~\ref{sec:noisy} shows that a cyclic belief update preserves counting
accuracy with noisy event features. These comparisons extend the test to
image cues and check the information available in frozen phase states.

\subsection{State-tracking adapters}
\label{app:adapters}
The adapters use the official DeltaProduct layer at commit
\texttt{d62241a}, with one 16-dimensional head, value expansion two, output gate,
negative eigenvalues, no convolution or forgetting, and a residual feedforward
block. DeltaNet uses one Householder update and DeltaProduct two. The CPU
recurrent kernel is verified against independent dense outputs and gradients.
Streaming and full-sequence evaluation agree. Both adapters use the same
compact policy configuration.

\subsection{Gaussian event features}
\label{app:gaussian}
The Gaussian observations have 16 dimensions and noise SD $0.25$.
The exact-angle variant uses a straight-through quantizer with the original
injection and readout. The training and evaluation protocol is in
Appendix~\ref{app:clean-training}. Table~\ref{tab:newseq2} shows that the
learned cyclic counter sustains high accuracy at long lengths for $k=2,3,4$.

\subsection{Image observations}
A shared CNN and the memory are trained jointly from raw MNIST images. Odd
digits constitute latent events. Only terminal reward supervises their count
modulo $k$. The first 50,000 training images are used for training and the
remaining 10,000 for validation. Evaluation uses the official test set. Training lengths
$1,2,4,6,8$ include short credit-assignment paths. A2C uses batch 128, learning
rate $0.001$, and 6,000 updates. Evaluation uses 2,048 episodes per seed.
Table~\ref{tab:newvision} shows that the cyclic counter and wider LSTM
retain the most accuracy as the image sequences grow longer.
